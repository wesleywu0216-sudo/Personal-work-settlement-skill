# 美股长期个股研究流程

## 1. 证券身份与适用性

研究输入至少需要公司名或交易代码；研究截止日可选，未提供时使用本次研究日。若可靠来源能把代码唯一解析为一只受支持的美国上市普通股，可自行核验并记录交易所；只有代码、上市地、证券类别或股份类别仍有歧义时才向用户追问。核对法定公司名、证券类别、主要上市地、报告币种和最新报告期，防止混入相似代码或集团内另一证券。

本 Skill 适用于美国上市普通股。ADR 或不同普通股类别可以继续，但必须说明投票权、经济权利、存托费用、汇率或转换关系等差异。ETF、ETN、封闭式基金、权证、优先股、并购前 SPAC 及其他非普通股工具不适用；确认类型后停止，并建议对应的专用研究流程。

身份无法唯一确认、输入不足或证券类型不适用时，流程状态为 `无法评估`。这是独立停止状态，不属于五档投资研究标签。身份停止的最小输出仅包含：停止原因、已核验证据、缺失项或不适用类型、下一步。不得生成公司或行业结论、四卡评分、估值判断或五档标签。

## 2. 实时数据硬规则

凡称“当前”“最新”或给出价格、估值、技术值，数据必须来自本次研究实际访问且用户可打开的来源。记录来源链接、访问时间、交易所时区、收盘或盘中状态、币种、复权口径；非交易日使用最近交易日并写明日期。不同日期或口径的数据不得静默拼接。

无法联网、来源打不开或数值无法核验时，明确说明工具限制，不给当前数值，不给受影响评分卡的数值，也不使用 `值得跟踪`、`等待价格` 或 `可考虑介入` 等正向标签。其他不依赖实时数据的历史事实仍可研究，但必须绑定数据期和来源。若缺失的是身份、持续经营、核心业务或行业经济性等最低关键证据，则转为 `无法评估`。

## 3. 原子硬门槛

每个原子项单独记录状态、证据、数据期和来源，不得把多个判断合并成一个笼统结论。

### 状态定义

- `通过`：当前且可核验的一手或可靠证据支持该项判断。
- `失败`：可靠证据直接否定该项，且影响重大，足以破坏长期研究命题。
- `有条件通过`：存在非致命缺口，但已有可靠证据使方向可以判断；必须列出条件和补证项。
- `未知`：证据不足，无法判断方向。

### 公司门槛

| ID | 原子检查项 |
| --- | --- |
| C1 | 主要产品、客户价值及收入来源可解释。 |
| C2 | 收入、客户、地区与供应链集中度及其影响可核验。 |
| C3 | 竞争优势存在可验证证据，并能说明持续期限与侵蚀路径。 |
| C4 | 单位经济、利润率或现金消耗与规模扩张关系可解释。 |
| C5 | 盈利质量、现金转换或研发成果转化与会计口径可核验。 |
| C6 | 资产负债表、偿债、融资和持续经营能力足够。 |
| C7 | 再投资、并购、回购、股权激励与稀释等资本配置可接受。 |
| C8 | 管理层激励、治理、审计、诉讼和监管风险未直接破坏命题。 |

### 行业门槛

| ID | 原子检查项 |
| --- | --- |
| I1 | 行业边界、价值链和公司所处环节明确。 |
| I2 | 需求驱动、周期性及关键领先指标可解释。 |
| I3 | 竞争格局、进入壁垒和议价权有可靠证据。 |
| I4 | 行业利润池存在，公司有获得或保住利润池的路径。 |
| I5 | 监管、许可、报销或政策约束可识别。 |
| I6 | 技术替代、供需或产能变化的影响可判断。 |
| I7 | 公司相对份额、成本、品牌、渠道、数据或研发位置可比较。 |
| I8 | 行业适用的经营指标和估值方法已确定且有可用数据。 |

允许开展范围受限的补证研究，仅用于解决 `未知`。若未知项涉及身份、持续经营、核心业务或行业经济性等最低关键证据，补证完成前状态为 `无法评估`；若最低证据已满足而只剩非关键未知项，可完成快速体检，但禁止正向标签和完整深研结论。任何 `有条件通过` 或 `未知` 都必须列出下一步、观察指标和转为通过或失败的阈值。

## 4. 第一阶段：快速体检

先完成身份、实时数据条件和全部原子门槛，再给结论。若触发 `无法评估`，立即使用停止输出，不继续公司/行业结论、四卡或标签。

未触发停止时，分别初评宏观环境、估值吸引力、技术状态、风险可控度及各自置信度。宏观使用“宏观变化 → 行业变量 → 公司财务驱动 → 现金流或估值影响 → 可观察指标”传导链；技术面仅用于介入时机。

快速体检的最小输出为：证券身份和类型、研究截止日与实时数据口径、原子门槛表、公司与行业简析、可评分的四张独立卡及置信度、标签资格说明、唯一研究标签、关键证伪、跟踪指标、缺口、来源和一般研究免责声明。无法核验的卡标记 `不评分` 并说明工具或证据限制，不补造数值。

## 5. 第二阶段：完整深研

只有“用户明确请求完整深研”且 C1–C8 与 I1–I8 全部 `通过` 时才能进入完整深研。快速体检即使 16 项全部通过，也只完成模板 B 并报告是否具备深研资格，不自动扩大为完整深研。用户直接要求深研时仍先执行门槛；`有条件通过` 或 `未知` 只能进行补证研究，不能输出完整深研结论。

公司深研覆盖产品与客户价值、分部与集中度、竞争优势、增长与单位经济、利润和现金转换、资产负债表、资本配置、治理与会计质量，并形成基准、乐观、悲观情景及各自证伪点。

行业深研覆盖价值链利润分配、供需和产能、竞争格局、议价权、监管、技术替代、周期位置和行业领先指标。把公司的份额、成本、品牌、渠道、数据、许可或研发能力放回行业比较，区分结构性、周期性和暂时性优势。

完整深研的最小输出包括快速体检全部字段，以及公司和行业深研、行业适用估值与反向估值、情景假设、完整风险矩阵、证据冲突处理和深研结论。四张 0–100 卡分别列出分项、权重、锚点、证据、置信度和缺口，永不合成总分。

## 6. 标签资格矩阵

五档标签都是证券的研究状态，不是个性化买卖、仓位或适配建议。用户索要个性化买卖或仓位时，不输出该建议；将请求转为一般性公司、行业、估值、风险和情景研究。

| 门槛与证据状态 | 允许标签 | 资格要求 |
| --- | --- | --- |
| 任一原子门槛 `失败` | `回避` | 说明重大否定证据、影响和可能失效条件。 |
| 无失败，但存在非关键 `未知` | `观察` | 列出补证、观察指标和转态阈值；未知消除前不得给更正向标签。 |
| 无 `未知`，但存在 `有条件通过` | `观察` 或 `值得跟踪` | `值得跟踪` 仅在核心命题有可靠正向证据且补证路径明确时使用；否则为 `观察`。 |
| 全部门槛 `通过`，但当前估值证据不足或风险不可控 | `观察` 或 `值得跟踪` | 说明选择依据；`值得跟踪` 仅在核心命题有可靠正向证据且补证路径明确时使用，否则为 `观察`。不得升级为 `等待价格` 或 `可考虑介入`。 |
| 全部门槛 `通过`，估值证据已核验但无安全边际，且风险可控 | `等待价格` | 业务命题成立，但当前价格未提供足够安全边际。 |
| 全部门槛 `通过`，估值证据已核验、有安全边际且风险可控 | `可考虑介入` | 行业适用估值、反向估值和风险矩阵共同支持；仍仅是一般研究状态。 |

身份失败或最低关键证据不足不进入矩阵，统一为 `无法评估`。标签依据门槛、证据、估值安全边际与风险可控性逐项判断，不得按四卡分数或任何评分阈值机械映射，也不能由技术强势越级。

## 7. 四项独立评分

- 宏观环境：使用标准传导链，明确受益、受损或影响不对称。
- 估值吸引力：使用行业适用模型、可比基准和反向估值，说明当前价格隐含的增长、利润率、资本成本或成功概率。
- 技术状态：描述趋势、成交和关键价位，只辅助介入节奏。
- 风险可控度：使用“风险事件、概率、影响、可能时限、领先指标、证伪阈值、缓释措施、应对方式、残余风险依据”九列矩阵；概率与影响统一使用 `Low / Med / High`，评分置信度仍使用 `High / Medium / Low`。

每卡独立评分与置信度。资料缺失、冲突、过时或实时数值无法核验时，降低置信度或标记 `不评分`；不得合成总分，也不得用一张卡补偿硬门槛。

## 8. 异常处理与证据纪律

- 资料冲突：并列来源、口径和日期，优先监管披露与可复核原始数据；未解决时使用区间或多情景。
- 历史过短：缩短可验证结论期限，增加同业、产品、客户与现金消耗证据，不把短期高增长外推为长期稳定率。
- 负利润或无稳定自由现金流：不用市盈率硬套，使用现金跑道、单位经济、盈亏平衡、稀释、行业适用模型和反向估值。
- 多业务公司：按分部使用适用指标和估值，处理公司费用、净债务、少数股权、协同与折价；分部证据不足则降低置信度或停止相关结论。

优先使用监管文件、公司正式披露、政府或行业原始数据；二手资料仅补充背景和争议观点。区分事实、公司口径、外部估计和分析推断。每个关键数字记录数据期、发布日期、访问日、单位和可打开链接。
