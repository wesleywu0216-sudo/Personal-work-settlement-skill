# 美股研究报告模板

按核心流程产生的研究状态选择模板。模板不是填空比赛：没有证据的字段应明确写“未知”“缺失”或“不适用”，其中“不适用”仅用于普通字段，门槛表仍仅使用四种状态，不得为了填满字段编造事实、数值、链接、评分或结论。正文中的当前数据均需标注 `as of`；所有证据和引用遵循《证据来源与引用规范》。

## 最终发送前静默自检（硬门禁）

发送报告前在内部逐项核对，不向用户展示自检过程。任一项不满足时，先修正报告再发送：

- **输出顺序**：模板 B / C 的首个实质章节是证券身份与研究 `as-of`，紧接完整门槛表；C1-C8 与 I1-I8 的第 16 行完成前，没有五档标签、四卡结果汇总、执行摘要，也没有“结论先行”“先说结论”“研究结论”或同义暗示。无法可靠完成门槛判断时已改用模板 A。
- **16 项门槛**：C1-C8、I1-I8 全部逐行出现，原文、状态、证据和模板要求的非通过字段没有合并或省略。
- **四卡强制列**：每张卡均逐列保留 7 个表头：`分项`、`权重`、`分项分`、`加权贡献`、`证据与发布日期 / 数据期 / 访问日期 / 口径`、`评分理由 / 锚点映射`、`缺口`；卡名、固定分项、权重和锚点未改名或压缩。
- **结果与置信度词表**：结果只用`正式分 / 暂定分 / 不评分`；置信度只用`High / Medium / Low`。`不评分`后没有`/100`或其他数字。
- **覆盖率与技术时点**：每个计分分项都满足 scorecards 的最低证据；缺失项未计入覆盖率。技术卡的标的与基准来自同一来源、同一截止日和一致复权口径，不存在“附近日期”或错位一个交易日仍计分。
- **无总分**：不存在跨卡总分、平均分、加权分、综合分或统一排名。
- **风险完整九列**：风险矩阵逐列保留`风险事件 / 概率 / 影响 / 可能时限 / 领先指标 / 证伪阈值 / 缓释措施 / 应对方式 / 残余风险依据`；概率和影响只用`Low / Med / High`，缓释、应对与残余风险依据未合并。
- **证据账本完整且原子化**：逐列保留`claim ID / 主张 / 类型 / 来源标题 / 发布者 / URL 或文件定位 / 发布日期 / 数据期 / 访问时间 / 单位、币种、会计口径 / 直接或间接 / 状态 / 用途`；每行只有一项可证实或证伪的原子主张，类型只用`事实 / 公司口径 / 外部估计 / 分析推断`之一，状态只用`confirmed / conflicted / unverified`之一，访问时间包含日期、时间和时区。
- **正文近链**：事实、公司口径、外部估计及关键推断在正文相邻位置有可打开链接或精确文件定位，末尾账本没有代替正文引用。
- **标签资格**：全文只有一个五档标签，且它在 16 项门槛之后首次出现，并逐项满足标签资格矩阵；模板 A 没有五档标签。

本文件以下所有表头均为固定 schema。除明确标为可选的内容外，不得压缩、合并、改名、删除或用散文替代表头中的任何强制列。

## 模板选择

| 流程状态 | 使用模板 |
|---|---|
| 证券身份、关键监管文件、关键门槛证据或其他停止条件未满足，无法形成可靠判断 | 模板 A：无法评估 |
| 用户请求快速体检，或用户请求深研但 16 项尚未全部`通过`；证券核验与最低关键证据满足 | 模板 B：快速体检 / 补证报告 |
| 用户明确请求完整深研，且 C1-C8 与 I1-I8 全部`通过`、最低关键证据满足 | 模板 C：深度研究 |

不得为了获得更完整或更正向的输出而越级使用模板。模板 C 同时要求用户的明确深研请求与全部门槛通过；快速体检即使全部门槛通过也保持模板 B，只报告是否具备深研资格。深研中新出现`失败`、`有条件通过`或`未知`时，停止完整深研并退回模板 B；若最低关键证据不足，退回模板 A。任一门槛`失败`时，模板 B 的唯一标签为`回避`。估值证据不足或风险不可控只影响标签资格，不因结论较保守而降低已经满足双重准入条件的模板 C。

### 五档标签资格矩阵

五档标签只能是`回避 / 观察 / 值得跟踪 / 等待价格 / 可考虑介入`，不得增加第六档。`无法评估`是模板 A 的停止状态，不是标签。

| 门槛与证据状态 | 允许标签 | 资格要求 |
|---|---|---|
| 任一原子门槛 `失败` | `回避` | 说明重大否定证据、影响和可能失效条件。 |
| 无失败，但存在非关键 `未知` | `观察` | 列出补证、观察指标和转态阈值；未知消除前不得给更正向标签。 |
| 无 `未知`，但存在 `有条件通过` | `观察` 或 `值得跟踪` | `值得跟踪` 仅在核心命题有可靠正向证据且补证路径明确时使用；否则为 `观察`。 |
| 全部门槛 `通过`，但当前估值证据不足或风险不可控 | `观察` 或 `值得跟踪` | 说明选择依据；`值得跟踪` 仅在核心命题有可靠正向证据且补证路径明确时使用，否则为 `观察`。不得升级为 `等待价格` 或 `可考虑介入`。 |
| 全部门槛 `通过`，估值证据已核验但无安全边际，且风险可控 | `等待价格` | 业务命题成立，但当前价格未提供足够安全边际。 |
| 全部门槛 `通过`，估值证据已核验、有安全边际且风险可控 | `可考虑介入` | 行业适用估值、反向估值和风险矩阵共同支持；仍仅是一般研究状态。 |

最低关键证据不足直接使用模板 A，不进入标签矩阵。标签依据门槛、证据、估值安全边际与风险可控性逐项判断，不得按四卡分数或任何评分阈值机械映射。五档标签只表示证券研究状态，不包含个人适配、仓位或买卖指令；宏观和技术不能覆盖任何门槛失败。
