# 证据来源与引用规范

本规范用于美股研究中的取证、核验、冲突处理和研究快照管理。任何评分、门槛判定、情景假设和研究状态标签都必须能回溯到证据账本。证据质量优先于材料数量；重大事实应尽量由一手来源确认。

## 1. 按主张类型选择来源

不存在对所有主张都适用的全局硬排序。先识别主张类型，再选择对该主张负有记录、监管或裁判职责的一手来源；同类来源冲突时，优先原始、完整、较新且口径可复核的材料。

| 主张类型 | 首选来源 | 交叉核验与补充来源 |
|---|---|---|
| 财务报表、会计政策、股本、治理与重大合同 | SEC 的 10-K、10-Q、8-K、DEF 14A、Form 4、13D/13G、注册声明等；非美国发行人或 ADR 同时查发行人本国监管申报 | 公司 IR 原始附件、审计报告、存托协议、主要交易所公告 |
| 监管许可、执法、规则和政策 | 对该事项有主管权的监管机关或政府部门，例如 Fed、Treasury、FDIC、FDA、FTC、DOJ、BEA、BLS | 行政决定、规则原文、正式统计说明、相关主体监管申报 |
| 诉讼与行政争议 | 法院案卷、判决、诉状、行政案卷或主管机关正式文件 | 当事方监管披露；新闻仅补时间线，不替代案卷事实 |
| 价格、成交、指数和公司行动 | 主要交易所、指数编制方、公司行动公告或能明确证券、时点、币种和复权口径的可核验行情源 | 第二行情源用于异常值核对；ADR 同时核对存托行、注册地监管及主要交易所资料 |
| 公司目标、指引及管理层解释 | 公司正式公告、财报稿、财报演示、电话会实录或录音、投资者日材料 | 后续监管申报、实际经营数据、客户或竞争对手文件；这些来源只能确认或检验公司口径 |
| 行业规模、竞争、技术与标准 | 行业主管机关、行业协会、竞争对手监管文件、学术论文、技术标准和标准组织资料 | 方法透明、数据可追溯的高质量第三方研究 |
| 近期事件 | 事件责任方公告、监管文件、法院或行政案卷 | 高质量新闻用于发现事件和补充时间线，随后回到原始来源核验 |

一手来源优先原则始终有效：重大事实尽量由至少一项一手证据确认。高质量第三方研究用于补充方法、外部估计和争议观点；新闻仅补近期事件；社交媒体、搜索摘要和 AI 摘要仅作为线索。

## 2. 证据使用原则

- 重大事实尽量以一手资料确认；若只能使用间接来源，必须说明原因、证据链和不确定性。
- 电话会、财报稿、演示文稿和管理层访谈中的展望、目标、解释或判断，应明确标注为**公司口径**，不得写成已经发生的客观事实。
- 将以下四类内容分开表达：
  - **事实**：可由原始文件或可核验数据直接支持。
  - **公司口径**：公司、管理层或其正式代表提出的目标、解释、预期或判断；证据只能先确认该表述存在，不自动证明其内容真实。
  - **外部估计**：来自第三方预测、行业模型或市场一致预期，并标明提供者与日期。
  - **分析推断**：研究者基于事实、假设和计算得出的结论，必须展示关键假设与推导方法。
- 每个 claim 只能选择上述一种类型，禁止填写`事实/公司口径`等混合类型。一句话同时包含已发生事实和管理层解释、目标或预期时，必须拆成两个 claim、两行账本，分别标为`事实`与`公司口径`；其他类型混合时同样拆行。
- 搜索结果摘要、AI 摘要、无法实际打开的页面、只有标题而无正文的页面，均不得作为关键证据。
- 单一材料中的管理层陈述不能自动证明其真实性；涉及竞争、市场份额、产品效果或行业规模时，应优先寻找监管资料、客户或竞争对手文件、行业数据等交叉证据。

## 3. 证据账本

每项影响门槛、评分、情景或标签的主张都应进入证据账本。一条原子主张对应一个 claim 且只选一种类型；一条主张有多个来源时，可增加多行并使用同一 claim ID，但不得借此把不同类型的主张合并。

| 字段 | 填写要求 |
|---|---|
| claim ID | 唯一且稳定的编号，例如 `CLM-001`；后续更新不复用已废弃编号 |
| 主张 | 可被证实或证伪的单一陈述，避免把多个结论混在一行 |
| 类型 | `事实`、`公司口径`、`外部估计` 或 `分析推断` |
| 来源标题 | 文件、网页、数据表或电话会的正式标题 |
| 发布者 | SEC、公司、政府机构、交易所、研究机构等 |
| URL / 文件定位 | 可直接打开的链接；本地文件写文件名、页码、章节、表格或行号 |
| 发布日期 | 来源首次发布或提交日期 |
| 数据期 | 该数据对应的季度、财年、月份、日期或区间 |
| 访问时间 | 实际打开并核验的日期与时间，含时区 |
| 单位 / 币种 / 会计口径 | 例如 USD 百万、GAAP、non-GAAP、名义值、实际值、季调等 |
| 直接 / 间接 | `直接` 表示来源直接支持主张；`间接` 表示需经解释、换算或推导 |
| 状态 | `confirmed`、`conflicted` 或 `unverified` |
| 用途 | 明确写出用于哪个门槛、评分项、估值假设或情景 |

状态定义：

- `confirmed`：证据已实际打开，身份与口径一致，足以支持该主张。对`公司口径`，`confirmed`只确认“该表述存在且记录准确”，不表示表述内容已被外部证实；内容是否获验证应另建`事实`claim并连接独立证据。对`分析推断`，`confirmed`只表示公式、输入、假设与计算过程可复核，不表示预测或未来结果正确。
- `conflicted`：两个或以上可信来源或口径产生尚未消除的差异。
- `unverified`：只获得线索、页面无法打开、关键上下文缺失，或证据不足以支持主张。

分析推断还应在账本旁记录公式、输入值、换算步骤和假设来源，使另一位研究者能够复算。若计算依赖多个 claim，应列出全部 claim ID。

## 4. 时效与 as-of 规则

### 4.1 当前价格与技术数据

- 必须在本次研究中实际访问数据，不得用记忆、旧报告或搜索摘要填入当前价格与技术指标。
- 记录交易所时区、取值时间、盘中或收盘、是否复权及复权方式、最近交易日。
- 非交易日应使用最近一个交易日，并明确写出该日期；不得把周末或节假日当作最新交易日。
- 所有当前数值在正文中标注 `as of YYYY-MM-DD HH:mm [时区]`，只有日线收盘数据时可省略时间但不可省略日期。

### 4.2 公司财务资料

- 使用截至研究截止时间**最新已向 SEC 提交**的适用文件，并记录提交日期与报告期。
- ADR 或非美国发行人还应核对发行人注册地监管申报、适用的 Form 20-F/6-K、存托协议及主要交易所资料；说明基础证券、ADR 比率、币种、投票权、存托费用与转换关系。
- 区分财报稿、财报演示与 SEC 完整文件。财报稿可用于快速阅读，但关键财务、风险因素、会计政策、承诺事项和脚注应回到 SEC 文件核验。
- 若 10-K/10-Q 与后续 8-K、修订文件或重述存在关系，应说明采用版本及原因。

### 4.3 宏观与行业资料

- 宏观数据使用截至研究截止时间的最新发布版本，同时记录数据期、发布日期、是否初值/修订值以及季调、年化等口径。
- 后续修订可能改变结论时，保留本次研究所用版本并设置复核触发器。
- 长周期行业、学术或标准资料必须注明资料年代及为何仍适用，不得把历史结构性资料写成当前市场事实。

### 4.4 无法联网或无法核验

无法联网、页面打不开、权限受限或来源无法复核时，不得凭记忆补写当前数值、具体链接或正向研究状态标签。相关字段应留空并标记 `unverified`，按停止或降级规则处理。

## 5. 冲突处理

发现数值或结论不一致时，先逐项检查：

1. 是否为同一证券、同一类别股份或同一法律实体；
2. 是否为同一报告期间、截止日与财年定义；
3. 是否混用了 GAAP 与 non-GAAP；
4. 是否混用了自然年、公司财年、季度累计值与单季值；
5. 是否存在币种转换、汇率时点差异；
6. 是否受拆股、合股、复权或每股口径变化影响；
7. 单位是否一致，例如元、千、百万、十亿或百分比与百分点。

处理要求：

- 不能消除的冲突必须并列展示，账本状态标记为 `conflicted`，不得静默选择更有利于论点的数据。
- 原始监管文件和原始数据口径通常优先；若低优先级来源采用了更适合分析的再加工口径，应同时保留原始值、转换方法和采用理由。
- GAAP 与调整后指标并列展示，明确列出主要调整项；不得只展示调整后指标而省略 GAAP 基准。
- 冲突仍无法解决时，改用区间、多个情景或敏感性分析，并降低相关评分与结论的置信度。
- 若冲突直接影响原子门槛、标签资格或估值方向，应暂停对应判定，直至取得足够证据或明确按降级流程处理。

## 6. 防止引用错误

- 每个引用链接必须在本次研究中实际打开，并确认正文确实支持相邻主张。
- 不引用搜索结果页；应打开并引用原始页面或原始文件。
- 同一关键结论至少需要一项一手证据；重大争议、异常交易、监管风险或核心竞争优势应尽量增加第二个相互独立的来源。
- 不用一个来源支持其未直接涉及的多个结论；必要时拆分 claim。
- 禁止长篇复制来源内容。采用简短引文或准确转述，并保留页码、章节、表格等定位信息。
- 任何换算、年化、复合增长、利润率、每股值、情景估值或反向估值都应记录公式、输入、单位和假设，确保可复核。
- 正文链接应靠近它所支持的句子；证据账本负责完整审计轨迹，不能以末尾链接堆砌代替正文对应关系。

## 7. 数据缺失：停止与降级

### 7.1 必须停止对应结论

出现以下任一情况时，应停止受影响的门槛、评分、估值或标签判定，不得用零、行业平均或主观乐观假设填补：

- 无法确认证券身份、交易所、币种或报告主体；
- 关键监管文件未取得或无法打开；
- 当前价格、股本、净债务等估值关键输入无法核验；
- 影响硬性门槛的主张只有搜索摘要、社交媒体或无法验证的二手转述；
- 关键冲突可能改变通过/失败方向，但无法判断正确口径；
- 数据截止时间不明，或存在足以改变结论的重大后续事件尚未核验。

证券类型不适用，或停止条件使公司和行业分析均无法可靠开展时，使用“无法评估”模板；不得输出四卡、估值或五档标签。最低关键证据包括身份、持续经营、核心业务和行业经济性；其中任一不足都不得进入标签资格矩阵。

### 7.2 可以降级但必须披露

非关键数据缺失且不改变硬性门槛方向时，可以继续研究，但必须：

- 原子门槛只使用`通过 / 失败 / 有条件通过 / 未知`；证券不适用不进入门槛表，直接使用模板 A。
- `有条件通过`或`未知`必须列出成立条件、补证动作、观察指标以及转为`通过`或`失败`的阈值；不得默认通过。
- 评分结果只使用`正式分 / 暂定分 / 不评分`，置信度只使用`High / Medium / Low`。覆盖率等于有充分证据可评分分项的权重之和，不得移除不适用或缺失分项的既定权重。
- 任一评分关键输入缺失即`不评分`；关键输入齐全且覆盖率为 100% 才可给`正式分`；关键输入齐全、覆盖率为 80% 至低于 100% 且仅缺非关键分项时，才可给`暂定分`并固定为`Low`；其余情况均`不评分 / Low`。
- 列出缺失数据、已尝试来源及其对门槛、覆盖率、置信度、情景范围和标签资格的影响。
- 最低关键证据已满足但仍有非关键`未知`，或实时数据受限但未触发停止时，只能按标签资格矩阵进入`观察`；不得凭间接证据推出更强标签。

## 8. 完整深研快照冻结

模板 C 的完整深研必须冻结一个可复核的研究快照，至少记录：

- 研究截止时间和时区；
- 证券身份、交易所、ticker、主要上市类别与报告币种；
- 本次实际使用的行情、SEC/本国监管文件、公司资料、宏观数据和行业资料的版本、发布日期、数据期及访问时间；
- 证据账本冻结时间、关键计算输入，以及本次实际读取的门槛规则、评分卡和行业适配规则文件版本或 Git 修订；
- 截止时间后出现但尚未纳入分析的已知事件。

快速体检使用模板 B 的身份与 as-of、证据账本和关键输入记录作为精简快照，不强制重复填写版本字段。任何报告发布后都不得静默替换历史数据、来源或结论。需要更新时，应创建新版本，保留旧版，记录变更项、变更原因、触发来源和对门槛、四卡、估值及标签的影响。任何“最新”“当前”“截至目前”的表述只对该快照的 as-of 时间有效。
