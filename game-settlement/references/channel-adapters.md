# 渠道适配清单
用于读取实际文件后的映射确认；字段名会变化，下表不能替代当期文件检查。具体费率和主体条件不随包发布。

| 渠道类型 | 可用识别线索 | 必须确认 |
|---|---|---|
| 国内支付 | 商品名、业务类型、交易状态、收入、手续费 | 成功交易筛选；退款/提现/兑换；内部对账差异；实际费与CP费 |
| Apple | SKU、Quantity、Partner Share、币种、财务期间 | 财务日历；已付款或预估；退款；WHT和汇率资料；主体费率 |
| Google | Package ID、Transaction Type、结算币种 | charge/refund/fee/tax符号；无产品税费的分摊规则及余额 |
| Mycard | 产品名称、价格、数量、折数、付款金额、历史销账 | 当月销售与可结算回款区别；历史回款；PC拆分；币种 |
| Onestore | 产品ID、Payment Amount、VAT、结算币种 | 实际币种；税前后；费用及汇率 |
| 海外支付 | 订单/请求编号、Gross、Settlement Amount、Fees | 主体产品映射；币种；净额与流水；退款和调整 |
| 主机渠道 | 产品代码、Title、Sales Period、Payment Currency | SKU/DLC归属；地区；税费；实际回款与销售期间 |
| 群文件/人工表 | 财务、运营提供的PC数据、测试充值、退款 | 来源与版本；无法从账单推断缺失明细 |

识别顺序：字段组合 + 账户信息 + 产品ID + 明细期间；文件名只提供候选。
字段缺失或相似模板可能冲突时，给候选列表和缺口，不以最高置信度当作已确认。
Apple订单、税费与财务报告，或Mycard月报与销账表可能是一组联合输入，不要求“一文件对应一渠道一产品”。
费用扣减、税分摊和汇率换算先独立复算并保留结果引用，再进入合同分成；本包脚本不自动完成渠道级解析和分摊。
分摊需指定权重口径、零分母处理、精度和尾差归属；无规则不分摊。
