# 游戏结算 Skill 验证记录
日期：2026-09-09。版本：0.1.0。执行环境：Windows，Python 3.12；脚本声明兼容Python 3.10+，其他版本由仓库CI运行后另行确认。

## 结果
- 32项脚本测试通过：22项基本复算、4项示例边界、6项只读Excel检查。
- 官方技能创建工具的quick_validate通过；校验依赖仅安装在本机包外验证目录，不是技能运行依赖。
- 完全虚构的四类例子执行成功：联运360.00，明确净额分成350.00，主机汇兑扣预付2520.00，利润应付0.00及下期亏损-50.00。
- 使用检查器只读盘点123份用户提供的工作簿，共339张工作表，读取失败0；其中37份带外部工作簿引用。此项是结构读取验证，不是123份金额全部通过。
- 另对两份历史表中有完整输入缓存的两行，使用十进制独立复现既有公式，6个比较点匹配。观察阈值为0.005，仅用于该次缓存浮点误差比较，不是通用合同容差。
- 另遇一行订单输入无缓存值，未默认补零，未计入通过样本。
- 真实文件、金额、主体和路径均未纳入分享包。

## 测试过程与修复
先建立计算测试，缺少实现时22项失败；实现后通过。检查器同样先观察6项缺少实现的失败，再通过。
技能编写前独立代理对6个虚构场景的基线已能识别主要风险，没有发现该轮明显业务判断失败；不宣称技能使全部场景从失败变通过。
技能编写后独立代理试用四个脚本样例，并审阅10个公开场景。场景原来包含期望答案，该轮归为独立审阅，不称盲测。
独立审阅实测发现：零常量可变、零汇率未阻断、当期亏损被非负约束拒绝。
修复：锁定常量上下限；设置正汇率下限；允许当期亏损。先加入回归测试观察2项失败、1项业务异常，再修复后全部通过。
新增不附答案的blind-prompts.md，供不同客户端做迁移验收。
