# 游戏结算 Skill 设计
版本：0.1.0，日期：2026-09-09。

## 目标
在不同具备文件读取及代码执行能力的模型客户端中复用结算方法。覆盖发行游戏、手游及端游联运、独立主机、小游戏利润结算。先以历史对账单梳理规则和复算；不要求用户补原始账单才能开展只读分析。

## 组成
- game-settlement/SKILL.md：模型入口及模式选择。
- references：字段口径、四类业务规则、渠道适配、异常与交付检查。
- scripts：只读 Excel/ZIP 检查；按已确认结构化规则进行十进制复算。
- examples：完全虚构的四类样例。
- tests：计算边界、只读检查和行为场景。
- README：跨模型使用与 GitHub 发布方式。

## 能力边界
规则提取、只读分析、固定复算、指导生成和复核。第一版不是自动登录器或全渠道原始账单解析器，也不含通用 Excel 出函引擎。生成正式 Excel 时，需客户端有可靠的表格工具及已确认模板，生成后重新读取验证。

## 数据边界
分享包只含通用方法、代码及虚构样例。真实原始文件、合同参数、账单模板、公司信息及实际检查结果放在分享包之外；不得上传 GitHub。历史费率和内部筛选门槛不能作为默认规则。

## 可靠性
记录规则适用范围、生效期和证据；混合账期逐行保留；重复版本不自动选新；净额和流水分开；人工调整不归零；历史账单可作复算参照，但不自动视为已确认合同。
金额计算采用十进制字符串、明确舍入步骤、逐项计算轨迹；每个异常只阻断受影响结算单元。
验证分为结构、固定计算、独立代理行为、真实业务复算、其他模型客户端实测。前三级不能替代后两级。
