# 美股长期个股研究 Skill 设计规格

## 目标与边界

`researching-us-stocks` 覆盖所有行业的美国上市普通股长期研究。它不执行交易，不读取或推断个人财务状况，不输出个性化买卖、仓位或适配建议；用户索要此类建议时，转为一般性公司、行业、估值、风险和情景研究。

Skill 默认先快速体检，仅在公司与行业全部原子硬门槛通过后进入完整深研。`无法评估` 是身份或最低关键证据不足时的独立流程状态，不是五个证券研究标签之一。

## 架构

- `researching-us-stocks/SKILL.md`：触发、路由、硬规则与按需引用。
- `researching-us-stocks/references/research-workflow.md`：身份、实时数据、原子门槛、两阶段、标签和异常处理。
- `researching-us-stocks/references/scorecards.md`：四卡分项、权重、锚点与置信度。
- `researching-us-stocks/references/industry-adapters.md`：行业指标和估值模型。
- `researching-us-stocks/references/evidence-sources.md`：来源优先级、时效与冲突处理。
- `researching-us-stocks/references/report-templates.md`：停止、快速体检与完整深研模板。
- `researching-us-stocks/tests/behavioral-test-log.md` 与 `tests/baselines/`：案例元数据、行为断言和可审计原始输出。

入口只读取一次共同流程，并按评分、行业、证据或输出需要再加载对应引用。

## 身份、证券类型与停止状态

输入至少包含公司名或代码、交易所，可选研究截止日。核对法定公司名、证券类别、主要上市地、报告币种和报告期。ADR 与不同普通股类别可继续，但必须披露权利、费用、汇率和转换差异。

ETF、ETN、封闭式基金、权证、优先股、并购前 SPAC 等非普通股不适用；确认后停止并建议专用研究。身份失败或最低关键证据不足时输出 `无法评估`，最小输出仅为停止原因、已核验证据、缺失项、下一步；禁止公司/行业结论、四卡评分和五档标签。

## 两阶段与最小输出

### 身份停止

仅输出停止原因、已核验证据、缺失项或不适用类型、下一步。`无法评估` 不参加标签矩阵。

### 快速体检

依次完成身份、实时数据条件、原子门槛，再分析公司、行业与可评分的四卡。最小输出包含身份与日期口径、门槛表、公司和行业简析、四卡及置信度或未评分原因、标签资格、唯一研究标签、证伪、跟踪指标、缺口、来源和一般研究免责声明。

### 完整深研

只有全部公司和行业原子门槛通过后启动。最小输出在快速体检基础上增加公司与行业深研、行业适用估值、反向估值、情景、完整风险矩阵、证据冲突处理和深研结论。有条件通过或未知只允许为解决未知而补证，补证前禁止正向标签和完整深研结论。

## 公司与行业原子硬门槛

公司门槛逐项覆盖：业务和客户价值、集中度、竞争优势、单位经济、盈利或现金质量、资产负债表与融资、资本配置与稀释、治理审计与重大法律监管。行业门槛逐项覆盖：行业边界与价值链、需求与周期、竞争与壁垒、利润池、监管许可、替代与供需、公司相对位置、适用指标与估值方法。

每项单独记录状态、证据、数据期和来源：

- `通过`：当前且可核验的一手或可靠证据支持。
- `失败`：证据直接否定且影响重大。
- `有条件通过`：存在非致命缺口，但方向可判断。
- `未知`：证据不足。

若未知涉及身份、持续经营、核心业务或行业经济性等最低关键证据，流程为 `无法评估`。若仅余非关键未知，可做补证研究或快速体检，但补证前不能给正向标签或完整深研结论。

## 实时数据硬规则

“当前”“最新”以及价格、估值、技术值必须来自本次实际访问且用户可打开的来源。记录访问时间、交易所时区、收盘或盘中、币种、复权口径；非交易日使用最近交易日并写明日期。无法联网或核验时披露工具限制，不给当前数值或受影响卡分数，也不给 `值得跟踪`、`等待价格`、`可考虑介入`。最低关键证据也缺失时转为 `无法评估`。

## 四项评分独立

宏观环境、估值吸引力、技术状态、风险可控度分别以 0–100 评分，每卡有固定分项、权重、锚点、证据和独立置信度。禁止平均、加权、排序求和或生成总分。估值与技术分离，技术只辅助时机。资料不足、冲突、过时或无法实时核验时，降低置信度或标记未评分。

宏观使用“宏观变化 → 行业变量 → 公司财务驱动 → 现金流或估值影响 → 可观察指标”链；风险使用“风险事件、概率、影响、可能时限、领先指标、证伪阈值、缓释措施、应对方式、残余风险依据”九列矩阵。

## 五档标签资格

五档均是证券研究状态：

| 门槛与证据状态 | 允许标签 | 资格要求 |
| --- | --- | --- |
| 任一原子门槛 `失败` | `回避` | 说明重大否定证据、影响和可能失效条件。 |
| 无失败，但存在非关键 `未知` | `观察` | 列出补证、观察指标和转态阈值；未知消除前不得给更正向标签。 |
| 无 `未知`，但存在 `有条件通过` | `观察` 或 `值得跟踪` | `值得跟踪` 仅在核心命题有可靠正向证据且补证路径明确时使用；否则为 `观察`。 |
| 全部门槛 `通过`，但当前估值证据不足或风险不可控 | `观察` 或 `值得跟踪` | 说明选择依据；`值得跟踪` 仅在核心命题有可靠正向证据且补证路径明确时使用，否则为 `观察`。不得升级为 `等待价格` 或 `可考虑介入`。 |
| 全部门槛 `通过`，估值证据已核验但无安全边际，且风险可控 | `等待价格` | 业务命题成立，但当前价格未提供足够安全边际。 |
| 全部门槛 `通过`，估值证据已核验、有安全边际且风险可控 | `可考虑介入` | 行业适用估值、反向估值和风险矩阵共同支持；仍仅是一般研究状态。 |

身份失败或最低关键证据不足为 `无法评估`，不进入矩阵。标签依据门槛、证据、估值安全边际与风险可控性逐项判断，不得按四卡分数或任何评分阈值机械映射，也不能由技术强势越级。标签不包含个性化买卖、仓位或适配含义。

## 行业适配与异常处理

一般经营公司、银行/保险、生物科技/制药、大宗商品/周期、REIT 和多业务公司采用不同指标和估值模型。多业务公司分部研究和估值，再处理总部费用、净债务、少数股权、协同与折价。资料冲突并列口径，历史过短缩短结论期，负利润使用现金跑道、单位经济、盈亏平衡、稀释及行业模型，不套用市盈率。

## 证据纪律

优先监管文件、公司正式披露、政府与行业原始数据。关键数字记录数据期、发布日期、访问日、单位和链接；区分事实、公司口径、外部估计和推断。缺失或冲突必须降低置信度、标记未评分或停止，不得静默填补。

## 验收标准

1. 身份停止、快速体检、完整深研三类最小输出清楚，`无法评估` 与五档标签分离。
2. 公司和行业为原子门槛，四种状态定义、补证边界和深研资格可执行。
3. 证券类型路由覆盖不适用工具、ADR 和普通股类别差异。
4. 实时数据有本次访问、可打开来源和交易口径；工具受限时不造数值、分数或正向标签。
5. 五档标签资格矩阵与个性化建议边界完整。
6. 四卡独立，无总分；宏观链、风险矩阵、反向估值和行业模型可见。
7. 每个行为案例有完整元数据、expected/observed/result 和原始输出链接及哈希。
8. 所有引用文件和原始基线到位、链接校验通过、复测通过后才能发布。
