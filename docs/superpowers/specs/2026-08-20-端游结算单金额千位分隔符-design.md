# 端游结算单金额千位分隔符设计

## 目标

端游结算单中的所有金额保持数值和公式属性，同时统一显示千位分隔符及两位小数，例如 `1897996.46` 显示为 `1,897,996.46`。

## 范围

- 产品结算单金额单元格 `E5:H5`、`J6`、`L6:M7` 使用 Excel 数字格式 `#,##0.00`。
- 费率和分成比例继续使用 `0.00%`，不改变公式、金额值、舍入规则或模板布局。
- 汇总工作簿金额列已使用 `#,##0.00`，保持不变。
- `SKILL.md` 与输入映射参考明确金额显示格式，后续批次自动沿用。

## 覆盖策略

Skill 继续默认不覆盖同名文件。本次用户已明确授权覆盖正式输出，因此先将当前 `202607` 正式目录整体移入带时间标识的备份目录，再在原路径重新生成，确保旧文件可恢复。
